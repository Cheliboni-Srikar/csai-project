PNG files are displayed from content/study-guide.md using relative links. SVG files are editable versions. Keep both formats in this folder; after changing a diagram, update both copies and verify that its labels still match the chapter. Each diagram has a text description in the learner content.

Concept sources are listed and linked in [the study guide](../content/study-guide.md#references). Original diagrams illustrate those concepts using the project’s fictional examples; they are not copied textbook figures.
